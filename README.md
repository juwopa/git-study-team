# git-study-team

박주원 :"저장은 내 PC에만 파일을 저장해서 나만 볼 수 있는 것이라고 생각합니다.
반면 커밋은 인터넷에 PC에 저장한 파일을 인터넷에 올려서 다른 사람도 관리할 수 있게 해주는 것이라고 생각합니다."

김동햔 : "2번째, 5번째로 Pull을 진행하였고, Pull을 하지 않은 경우 로컬 저장소의 파일이 업데이트되지 않았습니다. Commit 메시지는 신경을 쓰지 못했습니다... Push시 원격 저장소에 제가 추가한 커밋이 올라갔으며, History탭에서는 다른 분들이 작업한 커밋 내용들이 표시되었습니다."

임현규 : "저장은 내 컴퓨터에 반영, 커밋은 Git에 반영하는거 같습니다. Pull은 3번째와 6번째에 진행했고, 커밋 메시지는 신경 쓰지 못했습니다. 충돌은 일어나지 않은 것 같습니다."

최성규 : "아직 정확하게 이해하지 못 하였습니다. 깃 허브 로그인 후 초대 수락 하겠습니다."





임현규 : 브랜치이름은 Feedback-현규라고 지었고, merge는 순서대로 하다가 파일명이 달라서 수정후 다시 진행했습니다.
